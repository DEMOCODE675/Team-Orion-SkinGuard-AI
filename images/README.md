# Images Folder

This folder contains sample skin lesion images for testing and documentation purposes.

## Usage
- Place test/sample images here for local development.
- Images in this folder can be used to demonstrate the app's analysis capabilities.
- Do NOT commit large image files (>10MB) to the repo.

## Example Structure
```
images/
├── benign_example_1.jpg
├── benign_example_2.jpg
├── malignant_example_1.jpg
└── malignant_example_2.jpg
```

## Notes
- Keep sample images small (<1MB each for performance).
- Use .jpg or .png format (supported by Streamlit uploader).
- For production, users will upload their own images via the UI.

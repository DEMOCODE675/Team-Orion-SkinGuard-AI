# Team Orion - skinguard-AI

**Problem:** Campus safety alerts are not centralized.

**Solution:** AI-powered real-time alert system using Firebase Realtime DB and ML Kit.

**MVP:** https://your-mvp-link.vercel.app

**Demo Video:** https://youtu.be/your-demo-video-link

**Google Technologies Used:** Firebase, ML Kit

**Setup:**

1. Clone repo
2. Add `.env` with Firebase config
3. Run `python app.py`

## Dataset

This project uses the HAM10000 skin lesion dataset.
Due to size and licensing constraints, the dataset is not included.

Download link:
https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000
